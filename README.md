# PinSnap – Web-App

Projektfotos aufnehmen, Stellen mit Pins markieren und an jedem Pin weitere Detailfotos hinzufügen (beliebig tief).
Läuft direkt im Handy-Browser, ohne Installation. Über „Zum Home-Bildschirm hinzufügen“ wird sie wie eine App gestartet.

## Funktionen
- Live-Kamera: Linsenwahl (0,5× Ultraweitwinkel / 1× / Tele, soweit vom Gerät gemeldet), Zoom-Stufen und stufenloser Zoom,
  Pinch-Zoom, Tippen zum Fokussieren, Blitz (Aus/Auto/An), Taschenlampe, Belichtungskorrektur, Selbstauslöser, Raster,
  Front-/Rückkamera. Fallback: System-Kamera und Galerie.
- GPS mit automatischer Adresse; Adresssuche mit Vorschlägen beim Tippen (OpenStreetMap). Fehlt im Vorschlag die
  Hausnummer, wird das Feld „Nr.“ markiert, damit man sie ergänzt. Alle Felder bleiben editierbar. Kartenvorschau.
- Pins setzen, umbenennen, verschieben, löschen; Unter-Pins auf Detailfotos; Pfad-Navigation.
- Notizen je Foto, Team-Liste mit Rollen, Projektbericht teilen/kopieren.
- Suche und Filter (Geteilt, Mit GPS, Ort), „Mehr anzeigen“.
- Zwei Beispielprojekte, eins mit echten Fotos von Wikimedia Commons (Urheber und Lizenz stehen in der jeweiligen Notiz).

Daten bleiben auf dem Gerät (IndexedDB im Browser).
